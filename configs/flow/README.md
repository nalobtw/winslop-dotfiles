# Flow Launcher theme

Copy `Winslop.xaml` into `%APPDATA%\FlowLauncher\Themes\`, then choose **Winslop Midnight Alley** in Flow Launcher Settings → Theme. Set the hotkey to **Alt+Space** in Flow’s settings. Do not assign Alt+Space in WHKD; it is intentionally left to Flow.

The theme uses the documented Flow theme keys for the window frame, query box and selection colours. Blur is disabled: Flow documents that blur makes Windows control the corner radius, preventing the theme from reliably forcing square corners. Set Flow UI size/scale from Settings; no reliable theme-level arbitrary window sizing contract was found.
