# Winslop Midnight Alley palette

A custom wallpaper-derived palette designed to sit comfortably beside Catppuccin Mocha. Its base is the wallpaper’s near-black indigo and smoky violet-grey; accent colours are subdued cyan, mauve, rose and peach from the illuminated signs.

| Role | Colour |
|---|---|
| Desktop background | `#151320` |
| Mantle | `#1A1726` |
| Bar | `#201D2C` |
| Module / tile | `#2B2839` |
| Hover / selected | `#3E3A4C` |
| Overlay | `#5B5366` |
| Shared border | `#777C90` |
| Text | `#C5BEB1` |
| Secondary text | `#A49AAE` |
| Mauve | `#B9A2D0` |
| Cyan | `#9FC3CD` |
| Sapphire | `#8FB3C2` |
| Dusty blue | `#879DBD` |
| Rose | `#CF879B` |
| Peach | `#D4A68F` |

**Opacity convention:** “85% transparency” is interpreted as 85% opaque (15% transparent), prioritising legibility. Blur is limited to selected popup surfaces, not normal application windows.
